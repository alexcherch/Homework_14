# Проект интернет-магазина

## Описание функционала проекта

### 1. Класс `Category` (Категории товаров)
- **Приватность данных**: Список товаров `__products` переведен в приватный статус, защищая структуру данных от прямого изменения извне.
- **Метод `add_product`**: Реализован специальный публичный метод для безопасного добавления объектов `Product` в категорию с автоматическим обновлением глобального счетчика товаров `product_count` на +1.
- **Геттер `products`**: Создано «умное» свойство (`@property`), которое возвращает весь список товаров в категории в виде отформатированных строк строго по шаблону: `Название продукта, X руб. Остаток: X шт.\n`.

### 2. Класс `Product` (Товары)
- **Альтернативный конструктор `new_product`**: Описан фабричный класс-метод (`@classmethod`), создающий объекты из словарей. Дополнительно встроена логика умного слияния дубликатов: при совпадении имени остатки на складе суммируются, а цена автоматически выбирается по максимальному значению.
- **Приватность и управление ценой**: Атрибут цены `_price` скрыт. Доступ к нему контролируется через пару декораторов `@property` и `@price.setter`.
- **Валидация цен**: Сеттер блокирует установку нулевой или отрицательной цены с выводом предупреждения в консоль.
- **Интерактивная защита**: При попытке снизить цену товара ниже текущей, система запрашивает ручное подтверждение пользователя в терминале (`y/n`).

### 3. Инфраструктура и Тестирование
- Написано **12 комплексных тестов** на базе `pytest`.
- Для проверки интерактивного ввода (`input`) применена фикстура `monkeypatch`.
- Для перехвата предупреждений в консоли (`print`) применена фикстура `capsys`.
- Инструментом `pytest-cov` сгенерирован HTML-отчет, подтверждающий **100% покрытие функционального кода тестами** (отчет принудительно зафиксирован в папке `htmlcov/` репозитория).
- Весь код прошел строгую автоматическую проверку качества линтерами `black`, `isort`, `flake8` и статическим анализатором типов `mypy`.
