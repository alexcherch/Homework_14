## Описание функционала проекта

В рамках данного этапа были реализованы:
- Класс `Product` для управления данными о товарах (название, описание, цена, количество).
- Класс `Category` для группировки товаров с автоматическим подсчетом общего количества категорий и уникальных товаров на уровне атрибутов класса.
- Инфраструктура тестирования на базе `pytest` с вынесением фикстур в `conftest.py`.
- Настройка отчетов покрытия кода тестами (`pytest-cov`), достигнуто 100% покрытие функционала.
- (Опционально) Функция подгрузки данных из JSON-файлов в модуле `utils.py`.
